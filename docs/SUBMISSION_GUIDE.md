# 提交与启动说明（BAYTECH 2026）

> 面向：赛事组委会 / 评委 / 需要复现的人
> 本说明与压缩包 `BAYTECH2026_可视化AI导演台.zip` 一起提交。

## 一、这是什么

**可视化 AI 导演台**——面向短剧编剧与导演的前期创作工具。
多角色在同一个叙事沙盘里行动，作者观察、干预、确认，最后整理成剧本与分镜草稿。
核心是**剧情结构层**：本场戏契约 + 5 个剧情节拍 + 8 项剧情检查。

## 二、运行环境

| 依赖 | 版本 | 说明 |
|---|---|---|
| Windows 10/11 + PowerShell | — | 也用 Git Bash 手工启动（见 §四.2） |
| Python | **3.13**（含 Windows `py` 启动器） | 后端 |
| Node.js | **18 或以上** | 前端（Vite + React） |
| 浏览器 | Chrome / Edge（需 WebGL2） | 3D 舞台；不支持时自动回退 2.5D 地图 |

**不需要联网、不需要任何 API Key 即可启动**（默认离线规则模式，见 §五）。

## 三、一键启动（推荐）

1. 解压压缩包到任意目录（路径**不要含空格或中文**，例如 `D:\baytech2026`）；
2. 在该目录打开 PowerShell；
3. 执行：

```powershell
./start.ps1
```

首次运行会自动把 Python 依赖装到 `backend/.depsclean`、前端依赖装到 `web/node_modules`（约 1–3 分钟，需联网）。
启动脚本会打印实际生效的运行模式，并核对端口。

4. 浏览器打开：**<http://127.0.0.1:5274/>**

停止服务：

```powershell
./stop.ps1
```

> 启动脚本会校验端口占用与进程身份，只停止它自己启动的进程（记录在 `.runtime/`）。
> 端口 8200/5274 被其它程序占用时它会直接报错，不会误杀其它进程。

## 四、手工启动（不用脚本时）

### 1. 安装依赖

```powershell
py -3.13 -m pip install -r requirements.txt
cd web; npm ci; cd ..
```

### 2. 两个终端分别启动

```powershell
# 终端 A：后端（API 8200）
$env:PYTHONPATH = "$PWD\backend\.depsclean"
py -3.13 -m uvicorn api.app:app --app-dir . --host 127.0.0.1 --port 8200

# 终端 B：前端（导演台 5274）
cd web
npm run dev -- --host 127.0.0.1 --port 5274 --strictPort
```

## 五、运行模式：offline / live

界面右上角常驻**模式徽标**，说明当前是谁在生成角色候选：

| 模式 | 触发条件 | 表现 |
|---|---|---|
| **offline（默认，开箱即用）** | 未配置模型密钥 | 角色候选由本地确定性规则生成；事件来源标记 `offline_rule_v1`；**不需要联网与密钥** |
| **live** | 项目根目录有 `.env` 且含密钥 | 角色候选、开场设定、契约与节拍由**真实模型**生成；事件来源标记 `llm` |

启用 live（可选）：

```powershell
Copy-Item .env.example .env
notepad .env      # 填入 DIRECTOR_LLM_API_KEY=sk-xxxx
./stop.ps1; ./start.ps1
```

`.env` 已被 `.gitignore` 忽略，**压缩包中不包含任何密钥**。
若显式设置 `DIRECTOR_MODEL_MODE=live` 却没有密钥，后端会**拒绝启动**并给出明确报错（不会静默降级）。

**无密钥时两处功能会明确报错（预期行为，不影响其余流程）**：
- 「生成美术素材」（需要图像模型）；
- 「润色剧本」（需要对话模型）。
界面会提示原因；其余所有功能（沙盘推进、剧情检查、分段、确定性剧本/分镜输出）均可正常使用。

## 六、评审快速验证路径（3 分钟）

1. 打开 <http://127.0.0.1:5274/>；
2. 在输入框写一句话（例：`董事会审议一份金额异常的合同，财务总监带来原始流水，法务发现授权记录缺少签名`），
   点「**拆解我的想法 →**」→ 查看**本场戏契约**与**5 个剧情节拍**（页面会标注来源：真模型 / 本地规则）；
3. 点「**确认设定，进入沙盘**」→ 舞台出现角色；
4. 点「**▷ 推进一步**」→ 底部时间线出现候选事件；点任一条，右栏显示「提议 → 检查 → 结果」；
5. 看右栏「**剧情检查**」：8 项状态（通过 / 偏弱 / 未发生）与建议；标注为**规则判断**；
6. 点「**提交剧情 ✓**」→ 再点「**进入下一段 →**」→ 右栏「剧情分段」可**按段回看**该段发生的事件；
7. 点右上「**整理输出 ↗**」→ 生成**场次卡 / 剧本草稿 / 分镜草稿**（标注"确定性渲染·未调用模型"）；
   有密钥时点「**润色剧本（真模型）**」可让模型润色，**来源标记必须全部保留**。

## 九、常见问题

| 现象 | 处理 |
|---|---|
| 页面提示「无法连接本地剧情服务」 | 后端未启动或已退出：查看 `.runtime/backend.stderr.log`，重新 `./start.ps1`；若是模型调用超时，重试该步骤即可 |
| 端口被占用 | `./start.ps1` 会直接报错并指明端口；先关闭占用程序，或改 `start.ps1` 顶部端口常量 |
| 3D 舞台黑屏 | 显卡/驱动不支持 WebGL2 时自动回退 2.5D 状态地图；点「切换 2.5D / 切换 3D」可手动切换 |
| 模型很慢或超时 | 真实模型有延迟；超时会明确报错并保留可复现草稿，重试即可 |
| 中文显示为乱码（控制台） | 仅为控制台编码显示问题，不影响功能；可执行 `chcp 65001` |
| 想清空数据重来 | 删除 `data/director.db`（会丢失已建场景） |

## 十、边界（如实说明）

- 这是**辅助创作工具**，不是"一键生成整部作品"；正式剧情必须由作者确认；
- 剧情检查是**规则判断**，可能漏判误判，只提示、不否决；
- 3D 为**程序化零件拼装**（室内 / 室外 / 载具 / 街景 / 矿洞五种形态 + 30 件零件），不是生成式 3D 世界模型；
- 未包含：视频生成、语音、多人协作、任意历史回退。
