## 候选校验：字段级可见降级（2026-09-20）

真实模型会提出违反世界规则的字段（非法地点、拾取已被持有/不在场的道具、披露自己不知道的事实）。
此前这些会让**整轮**返回 422，作者拿不到任何候选。现改为**字段级可见降级**：

| 情况 | 现在的行为 | 事件里的记录 |
|---|---|---|
| `move_to` 不在场景地点表 | 留在原地，其余动作保留 | `移动目标：地点不在场景表中，已留在原地` + `proposed` |
| 移动目标与当前地点不连通 | 留在原地 | `移动目标：与当前地点不连通，已留在原地` |
| 拾取无主/不在场的道具 | 忽略该操作，动作与对白保留 | `道具取用：该道具不在当前地点或并非无主，已忽略该操作` |
| 转交未持有/接收者不在场 | 忽略转交 | `道具转交：<原因>，已忽略该操作` |
| 披露自己不知道或已锁定的事实 | 忽略该条披露 | `信息披露：角色尚不知道该事实，已忽略` |
| 行动目标角色不存在 | 清空目标 | `行动目标：角色不存在，已忽略该对象` |

仍然是硬错误（保留 422）的只有**结构性问题**：缺少动作文本、引用不存在的角色、同一步同一角色重复事件、字段类型错误。

复演证据（`scene_c020e6b6488a`，live 模式）：一轮 3 个候选，ceo 提议了非法地点、legal 提议了非法取用，
两者都在事件里留下降级记录，**整轮成功返回**；预览后 `revision=0`，提交后 `revision=1`、正式事件 3；
场次卡/剧本/分镜三种输出均 `200` 且各自带 3 个来源事件 ID。

## 对白分段与阅读节奏（2026-09-20）

问题：长台词一次显示成一长串，观众来不及读；3D 说话气泡尤其明显。

改法（候选来源与采用范围见 `docs/REFERENCES.md` 的 2026-09-20 一节）：

1. 新增 `web/src/dialogue.ts`：`splitSentences`（按中英标点切句、过短碎片合并）→
   `splitDialogue`（每段不超过 14 字，优先在标点处断开）→ `chunkDurationMs`（约 6 字/秒折算，
   夹在 1.2–4 秒）→ `planDialogue`；参数集中在 `DIALOGUE_DEFAULTS`，可覆盖。
2. 3D 说话气泡改为**逐段显示**：到时自动切下一段，右下角显示「当前段 / 总段数」；
   事件变化时从头开始。
3. 舞台工具栏新增「**逐句显示 / 整段显示**」开关（写入 localStorage，随时可切）——保留用户对节奏的控制。
4. 后端候选提示词补一句「dialogue 尽量不超过 40 字，长台词拆成两三句」，从源头减少超长对白。

补充修正（同日）：气泡曾用 drei `Html` 的 `distanceFactor`，镜头拉近时整块被放大成**一条糊满画面**；
已改为**固定屏幕尺寸**，并把气泡宽度、行数写死上限；同时**最多只显示 1–2 个气泡**
（当前选中角色 + 最近一条事件的发言者），避免多人同时弹气泡。分段参数改为每段 ≤ 12 字，

## 3D 说话气泡防遮挡（2026-09-20，第二轮）

用户反馈（附截图）：两个气泡重叠在一起、各自还带动作+台词，等于两层白卡糊在场景上。三处同修：

1. **同一时刻只显示一个气泡**：优先当前选中角色，否则最近一条事件的发言者；不再出现气泡互相叠压。
2. **气泡只放台词**，动作交给底部对白窗（气泡里仅在完全没有台词时退化为显示动作，且截断到 24 字）。
3. **尺寸再收小**：宽度上限 `min(150px, 32vw)`、最大高度 72px、台词最多 2 行（超出省略），
   名字 10px / 台词 11px；背景透明度降到约 85%，透出场景。
4. 新增舞台栏开关「**气泡开 / 气泡关**」（localStorage 持久化）：完全不想要气泡时可一键关闭，
   此时信息仍完整保留在可拖动可缩放的底部对白窗里。

验证：`npm run build`（含 `tsc --noEmit`）通过；开发服务器已提供新组件。

## 对白窗可拖动、可缩放（2026-09-20）

需求：让窗口能被拖到任意位置并调整大小（3D 气泡锚在角色头顶，无法拖动，因此该能力做在**底部对白窗**上）。

实现（`web/src/WorldStage.tsx` 的 `FloatingCaption`，配合 `web/src/stage.css`）：

- **拖动**：按住窗口标题栏（含 ⣿ 抓手、显示 `cursor: move`）拖动，位置实时更新并夹在舞台范围内；
  标题栏上的按钮（展开/收起、重置）不触发放置拖动。
- **缩放**：两种状态都开启 CSS `resize: both`，右下角出现缩放把手；停靠态与浮动态都可调；
  最小 220×60（浮动）/ 240×60（停靠），最大不超过舞台可用区域。
- **记忆**：位置与尺寸写入 `localStorage`（键 `director-caption-box`），刷新后保持；
  拖动到任意位置后标题栏出现「重置」，可一键回到「底部居中」默认态。
- **内容**：未展开时仍限 2 行（点击「展开」看全文），文本区自身可滚动，窗口再大也不会溢出。

验证：`npm run build`（含 `tsc --noEmit`）通过；开发服务器已提供该组件。
未做：键盘微调（方向键）与移动端触摸缩放——CSS `resize` 在触摸设备上不生效，列入待人工项。

## 回看与连续演示

正式提交会写入不可变 checkpoint。`GET /api/v1/scenes/{id}/replay` 读取指定分支的历史帧，不修改当前正式状态；前端导演台提供播放、暂停、上一刻、下一刻、速度和进度条。回看模式是只读的，候选草稿和导演提交按钮会停用。

连续回看根据相邻历史帧中角色位置变化计算展示时长；角色使用路径点和步进动画移动，道具跟随持有角色。回看不会调用模型，也不会把历史帧写回正式剧情。
