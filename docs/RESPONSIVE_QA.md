# 响应式布局调整与验证记录

日期：2026-09-19

## 已实现

- 导演台使用浅色界面，桌面保留角色、舞台、检查面板三栏。
- 剧本与分镜、分支页面使用左导航和宽内容区，移除无关检查面板。
- 在 860px 以下，导航单独成行、角色横向滚动，保留编辑设定入口；检查面板放在舞台之后。
- 在 520px 以下，主要操作按钮重排，表单与输出使用单列，输入字号提高到 16px。
- 时间线样式与实际组件类名对应，候选和正式事件保留不同视觉状态。
- 修复复选框被通用表单样式撑宽的问题。
- 输出的来源事件默认折叠，展开后限高滚动，显示选中数量。
- 在 API 边界将后端 `kind: script` 映射为前端 `type: screenplay`，恢复剧本标题和下载名称。
- 没有使用根节点横向裁切隐藏布局问题。

## 已完成验证

- `npm run build` 通过，TypeScript 检查通过。
- 3D 模块独立加载；构建仍提示该模块约 878 kB，属于后续性能优化项。
- 前次后端离线测试 35 项通过，本次界面修改未重复执行后端测试。

## 尚未完成的视觉验收

已尝试 390 × 844 浏览器视口，但截图输出出现画布尺寸与内容占比异常，未形成可作为验收证据的截图。备用 Windows 截图接口返回 `SetIsBorderRequired / E_NOINTERFACE`。

因此不能据此声称所有手机页面没有溢出。仍需在正常截图环境中完成：

- 1440 × 900 桌面与 390 × 844 手机下的首页、场景设定、导演台、分支和输出截图。
- 320 / 375 / 768px 的实际宽度溢出检查。
- 3D 镜头取景、角色可读性、2.5D 切换、候选编辑和手机表单操作。

本轮没有调用真实角色模型，也没有推进演示主线以制造验收数据。
